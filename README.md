# Учёт товаров на складе

Консольная программа для учёта товаров на складе малого магазина.

## Назначение и аудитория
Программа ведёт список товаров, их количество и цену. Предназначена для
кладовщиков и продавцов небольших магазинов.

## Основные функции
1. Добавление товара (в том числе пополнение существующего).
2. Проверка наличия товара.
3. Расчёт общей стоимости товаров.
4. Просмотр списка товаров.
5. Списание товара со склада.
6. Передача данных между модулями в формате JSON.
7. Логирование ошибок и отладочный вывод.

## Структура
- `src/` — исходный код (warehouse.py, module_a.py, module_b.py, main.py, ...)
- `test/` — unit-тесты
- `docs/` — документация
- `config/` — настройки (settings.json)
- `scripts/` — вспомогательные скрипты
- `lib/` — дополнительные библиотеки

## Запуск
```
python src/main.py          # меню
python src/main.py --demo   # демонстрация интеграции модулей
pytest test                 # тесты
```
